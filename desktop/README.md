# webcam-bridge (desktop)

Desktop half of [Webcam Bridge](https://github.com/16SULPHUR/webcam-bridge):
receives the H.264 stream from the Android app over USB, applies effects
(backgrounds, touch-up, reactions, pets) and sends it to a virtual camera,
with a local web dashboard at <http://localhost:5134>.

```bash
pip install -e .            # from this folder
webcam-bridge --help
```

See the [main README](https://github.com/16SULPHUR/webcam-bridge#readme) for
setup, requirements and troubleshooting.
